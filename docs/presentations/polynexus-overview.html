18 / GUINIER

低 q 的一小段，
估计一个 Rg。

ln I(q) = ln I(0) − q²Rg² / 3

假设：qRg ≪ 1；斜率给出 Rg，截距关联 I(0)。

INPUTlow q过滤 beamstop 与聚集风险。
OUTPUTRg · I(0)附带拟合区间和 R²。
BOUNDARYqRg不满足条件就降级。
qRg ≪ 1
slope → Rg
限制：聚集、低 q 异常和窗口漂移会让结果进入 review。

20 / POROD ASSUMPTION

高 q 的尾部，
看见的是界面趋势。

I(q) ∝ q−n

Porod 的核心 assumption：尾部由界面散射主导。

INPUThigh q选择背景稳定的尾部。
OUTPUTn · Kp给出 Porod 斜率与常数。
OPTIONALSv在绝对标定和条件满足时计算。
log I = log K − n log q
背景、粗糙度和有限 q 覆盖会改变解释。

PreprocessIntent

对 baseline、smoothing 和 q-window，系统可以只接受“减弱平滑”“处理低 q 污染”“保护 Guinier 区域”等结构化意图。确定性服务再生成有限候选。
