SAXS / METHOD MAP

把方法放回它们
真正观察的区域。

SIZE / LOW-Q

Guinier

用低 q 区域的近似关系，估计整体尺度和低角趋势。

PERIOD / MID-Q

Bragg

峰位给出层片周期等特征尺度，是最直观的结构入口。

CORRELATION / MID-Q

γ(r) · IDF

把 q 空间信号转换到距离空间，观察周期和界面关系。

TAIL / HIGH-Q

Porod · Kratky

观察高 q 尾部、界面特征和结构趋势，而不是只看 R²。

SAXS / COMPLEMENTARY METHODS

同一个结构问题，
不只走一条路。

one result · many checks
01 · PEAK

Bragg position

峰位提供直观的周期尺度，最容易被研究者解释。

L = 2π / q*
02 · LORENTZ

Lorentz fit

在修正后的空间里拟合峰形，检查峰位与宽度的稳定性。

width · R² · residual
03 · CORRELATION

γ(r) / IDF

转换到距离域，观察第一极大值和结构尺度是否一致。

r-first-max · Lcorr
04 · INVARIANT

Scattering Q*

用积分得到不变量，连接两相体系和结构变化的整体约束。

Q* · φc · consistency

SAXS / REVIEWABILITY

不可靠的结果，
也要被明确标出。

分析软件真正的底线，不是每次都成功拟合，而是不要把失败伪装成成功。

✓

可用

拟合和物理约束相互支持，参数在合理范围内稳定。

usable · evidence attached
!

需复核

数值可以生成，但方法之间存在冲突或对参数敏感。

review required · keep context
×

不可用

数据不足、模型不适用或拟合失败，保留诊断而不伪造结论。

unusable · fail closed

AI / HUMAN-IN-THE-LOOP

一次调参，应该留下
一条可审阅的过程。

读取当前状态

输入、拟合、残差、质量级别和风险原因。

context first
02

解释建议

说明为什么改变窗口、线形或平滑参数。

reason + risk
03

用户确认

研究者决定是否接受这次候选重跑。

human gate
04

重新分析

使用明确的候选参数，生成新的结果对象。

bounded rerun
05

比较前后

同时看拟合、稳定性、物理性和数据质量。

evidence diff
