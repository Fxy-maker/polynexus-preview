18 / GUINIER

低 q 的一小段，
估计一个 Rg。

ln I(q) = ln I(0) − q²Rg² / 3

假设：qRg ≪ 1；斜率给出 Rg，截距关联 I(0)。

qRg ≪ 1
slope → Rg
限制：聚集、低 q 异常和窗口漂移会让结果进入 review。

20 / POROD ASSUMPTION

高 q 的尾部，
看见的是界面趋势。

I(q) ∝ q−n

Porod 的核心 assumption：尾部由界面散射主导。

log I = log K − n log q
背景、粗糙度和有限 q 覆盖会改变解释。
20 / 46
21 / POROD EXPONENT

一个指数，
带着一组 restriction。

Porod exponent n = slope in log I vs log q

restriction：高 q 背景、界面粗糙度、分辨率和窗口必须可见。
exponentn
windowhigh q
riskreview

22 / BRAGG PERIOD

峰位回答：
这个周期有多大？

d = 2π / q*

先确认 q* 和 peak assignment，再把周期带入结构讨论。

q* → d

修正改变 observable；原始曲线、修正配置和适用边界都要保留。
