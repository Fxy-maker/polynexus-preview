# SAXS 变温结果工作台视觉优化设计

**日期：** 2026-07-17  
**范围：** SAXS 变温结果展示区域的视觉层级和可读性优化  
**状态：** 待用户评审

## 目标

把当前“深色指标卡 + 原始表格 + 多处橙色状态文字”的结果区，优化为轻量、清晰、偏工作台的结果展示：用户能先读懂关键指标，再理解当前风险，最后查看逐帧数据和下一步操作。

本轮只处理结果展示组件的布局、颜色、间距、状态胶囊和操作区排列，不修改分析算法、结果字段、状态判断、导出/复制逻辑和其他技术页面的信息架构。

## 当前问题

- 指标卡使用整块深色背景，视觉重量过高，且 4 个指标在 3 列网格下会掉到第二行。
- 状态同时出现在数值单元格和可靠性单元格中，并以橙色文字重复强调，扫描成本高。
- 表格按内容宽度收缩，右侧留下大片空白，数据区不像一个完整工作台。
- 结果表、状态标签和底部操作按钮缺少明确的主次关系。

## 设计方案

### 1. 指标区

继续使用 `ResultsTablePanel` 的 hero metrics 数据，不改变 `HeroMetric` 结构。针对最多 4 个核心指标的 SAXS 变温结果：

- 4 个指标保持一行展示；超过 4 个时再按两行折叠；
- 白色/浅色卡片背景、细边框和 10px 左右圆角；
- 标签使用小号 muted text，数值使用更大的 primary text；
- 单元状态只显示为小型胶囊，使用浅绿/浅黄/浅红背景，不使用整块深色填充；
- 指标卡之间保持一致内边距和间距，避免最后一张孤零零掉行。

### 2. 判断提示条

在指标区和结果表之间增加一个可选的轻量判断条，使用现有 presentation model 的摘要/风险/下一步文本，不在组件内重新判断科学状态。

- 无风险时使用浅绿色或中性背景；
- 有复核或阻塞时使用浅黄色/浅红色背景；
- 左侧显示状态点和短标题，中间显示一句摘要和一句下一步；
- 右侧保留一个主动作按钮，主动作由外部窗口逻辑提供；
- 没有摘要时整条隐藏，不留下空白占位。

如果当前版本没有可直接传入的判断条模型，则先实现可复用的 `set_review_hint(...)` 接口和隐藏态，第一轮只由 SAXS 变温结果调用，其他技术保持不变。

### 3. 结果表

保留现有关键结果、完整明细、质量诊断三个 tab 和所有字段。仅优化呈现：

- 表头使用浅色背景、较低对比度边框和统一高度；
- 行高固定在易读范围，数值保持深色，状态不再通过整格橙色文字表达；
- 状态显示为紧凑胶囊，`reliable/review/blocked` 使用统一的颜色语义；
- 状态胶囊保留 tooltip 和可访问名称，完整解释继续放在 tooltip；
- 调整列宽策略，使表格使用更多可用横向空间，并避免无意义的超宽列；
- 复制、排序、导出行为完全不变。

### 4. 操作区

操作按钮按层级排列：

- 主要动作使用现有 `primary_btn` 样式，只保留一个视觉主按钮；
- 导出、复制、默认顺序使用轻量次级按钮并靠右排列；
- 不新增隐式运行、自动跳转或新的持久化状态。

## 文件边界

### 修改

- `polynexus/gui/widgets/results_table_panel.py`：hero metric 布局、状态胶囊、表格列宽和可选判断条展示。
- `polynexus/gui/theme.py` 或 `polynexus/gui/styles.py`：沿用现有主题 token，补充结果指标/状态胶囊的轻量样式；只选择实际生效的一套样式入口。
- `polynexus/gui/i18n.py`：如新增判断条或状态胶囊文案，补齐中英文 key。

### 测试

- `tests/test_results_table_panel.py`：补充 4 指标同排、状态胶囊颜色/文本和隐藏判断条测试。
- `tests/test_results_table_service.py`：只在需要确认既有模型字段未被改变时增加回归断言；不修改科学结果 fixture。

不修改 `polynexus/core`、SAXS 结果计算、导出服务、历史服务或其他技术页面。

## 降级与兼容

- 0 个 hero metric：指标区保持隐藏；
- 1–3 个 hero metric：按可用列数自然排列，不补空卡片；
- 4 个 hero metric：保持单行；
- 状态未知或没有状态：显示中性文本，不强行套用风险颜色；
- 老结果缺少判断条字段：隐藏判断条，不影响表格、复制、导出和排序；
- 深色主题继续使用同一套语义 token，不能用固定浅色值破坏 dark mode。

## 测试策略

1. 离屏 Qt 测试验证 0–4 个 hero metric 的可见性和布局行列；
2. 验证 `reliable/review/blocked` 仍有清晰文本、颜色和 tooltip/accessibility 信息；
3. 验证判断条有文本时显示、无文本时隐藏；
4. 验证表格 tab、排序、复制和导出相关现有测试保持通过；
5. 运行结果面板定向测试、SAXS 结果展示回归测试和完整 pytest；
6. 手动检查浅色与深色主题下的结果区，确认指标不会再次掉行、表格不会被状态文字撑破。

## 验收标准

- SAXS 变温 4 个指标在同一行且不再使用整块深色背景；
- 用户能在 1 次扫视内区分“指标值、当前判断、逐帧状态、可执行操作”；
- 状态胶囊视觉统一，橙色/红色只用于需要关注的状态，不污染整张表；
- 表格横向空间利用更合理，核心数据不被截断；
- 浅色/深色主题都可读，现有结果逻辑和操作行为不回归。
