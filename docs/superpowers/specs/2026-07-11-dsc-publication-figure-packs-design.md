# DSC 论文级可编辑图包设计

日期：2026-07-11  
状态：已确认设计，待用户审阅后编写实施计划  
范围：继 SAXS 之后，为 DSC 建立技术语义独立的论文级图包

## 1. 目标

DSC 输出按实验模式自动形成 `Main / SI / Diagnostics` 三层图包，并复用已经完成的 Figure Document v2、对象级图片编辑器、统一发布和 publication audit。图包应服务于热转变、结晶行为和动力学结论，而不是把所有分析诊断图平铺到图库中。

Main 默认只有一张核心复合图；只有存在独立、可靠的第二条科学结论时，才生成第二张 Main 候选图。

## 2. 范围与边界

本周期覆盖 DSC 的单次热扫描、多样品/热历史比较、等温结晶和非等温动力学。

本周期不修改 DSC 的找峰、基线、积分、结晶度或动力学计算。图配方只能读取分析层已经确认的扫描曲线、热事件、积分结果、结晶度和拟合质量；不得在绘图层重新计算或替换物理参数。

SAXS 的图种、坐标语义和结论规则不得复制到 DSC；共享的仅是文档、编辑、发布、导出、审计和 manifest 生命周期。

## 3. 模式专属图包

### 3.1 单次升温/降温扫描

- Main：热流-温度主曲线，标出已确认的 Tg、冷结晶、熔融或结晶事件；只有结晶度和积分质量可靠时，才加入焓或结晶度面板。
- SI：基线、积分窗口、峰分离与重复扫描对照。
- Diagnostics：原始/平滑曲线、残差、低置信度峰和失败原因。

热流方向、吸放热符号和温度轴方向保持仪器数据与分析配置的既有语义，不因视觉统一而擅自翻转。

### 3.2 多样品或热历史比较

- Main：(a) 同一温度范围内的热流叠加曲线；(b) 可靠峰温、焓或结晶度的比较图。
- SI：各样品的积分范围、基线和重复性。
- Diagnostics：单样品异常、不可比较扫描条件和低置信度拟合。

至少两条可比较曲线才生成比较主图；趋势或统计面板至少需要三个有效样品/条件点。

### 3.3 等温结晶

- Main：(a) 相对结晶度-时间曲线及有效 Avrami 拟合；(b) 在存在多个可靠等温点时，半结晶时间或可靠动力学参数随温度的趋势。
- SI：全温度组拟合、拟合区间、残差与置信区间。
- Diagnostics：初始稳态判定、温度漂移、异常段和无效拟合。

Avrami 只有在时间轴、转化率区间、拟合质量和参数均有效时才可进入 Main；否则保留在 SI 或 Diagnostics。

### 3.4 非等温动力学

- Main：(a) 不同升降温速率下的转化率曲线；(b) 仅在各方法质量门通过时显示一张动力学关系候选图。
- SI：Kissinger、Ozawa、Mo、Friedman 中未被选入 Main 的方法证据。
- Diagnostics：拟合窗口、外推、点数不足、残差和低置信度参数。

不因某一方法产出数值就展示其结论；方法准入必须检查最小点数、线性/残差、温区一致性和外推限制。

## 4. 统一准入规则

- 只有分析层标记有效的峰温、焓、Tg、结晶度与动力学参数可作为 Main 中的定量结论。
- 基线敏感、积分失败、峰分离不稳定、低置信度或物理上不成立的结果不得进入 Main。
- 缺少可靠数据时删除整个面板，禁止空面板或诊断图填充 Main。
- 若无法形成任何可靠 Main 图，manifest 必须明确记录 `no_publication_ready_figure` 与原因；SI/Diagnostics 仍可保留可追溯证据。

## 5. 编辑、发布与资产

每张 DSC 图通过 Figure Document v2 表达真实多面板布局和对象。热流线、基线、积分区、峰温标线、拟合线、误差条、文字和图例均绑定到对应 panel/object，可在现有编辑器中独立选择和修改。

保存更新 working revision；重新发布更新 published revision，并输出同一修订的 Preview PNG、PDF、SVG 和 600 dpi TIFF。发布失败时必须保留上一版完整资产，并在 manifest 中记录失败原因。

## 6. 视觉规范

- 使用英文变量、规范单位和期刊尺寸；最终 Main 图最小可见字为 8 pt。
- 图内不放描述性大标题；使用 `(a)`、`(b)` 面板标签，完整叙事交给 caption。
- 使用色盲友好配色，同时以线型/标记区分数据；避免装饰性渐变、阴影和不必要网格。
- 不在同一面板混用双 y 轴；需要比较不同量纲时拆分为独立面板。

## 7. 验收

至少使用现有真实 DSC 数据覆盖：单次热扫描、等温结晶和非等温动力学。验收需证明：

- 每种模式生成稳定的 Main/SI/Diagnostics manifest；无可靠 Main 时有明确状态而非伪结论。
- 图库默认显示 Main，可切换 SI 和 Diagnostics，且打开同一 Figure Document。
- 多面板对象保存、关闭、重开和重新发布后不丢失。
- PDF、SVG、TIFF 和 Preview 来自同一 revision；TIFF 为各向同性 600 dpi。
- publication audit、失败回退、低置信度拦截和真实数据视觉复核均通过。

## 8. 后续顺序

本 DSC 周期完成并验收后，分别为 WAXS、IR、NMR 进入各自独立设计周期。它们可复用共享发布底座，但必须重新定义其模式、科学叙事与准入规则。
