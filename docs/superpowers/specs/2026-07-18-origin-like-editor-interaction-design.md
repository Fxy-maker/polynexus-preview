# Origin 式图像编辑器交互设计

日期：2026-07-18  
状态：用户已确认，待规格审阅

## 背景

已合并的 Origin 编辑器可用性工作补齐了注释对象、绘制工具、抽屉式
Inspector 与数据源导出诊断，但用户在实际 GUI 中仍遇到三个核心问题：

1. 左侧工具以裸文字纵排显示，缺少专业绘图工具应有的层级、图标和状态反馈。
2. 右侧 Inspector 仍承担过多创建、编辑和样式职责，形成密集按钮墙；画布操作不直观。
3. 文本不能通过拖拽得到文本框；直线、箭头和曲线没有形成可预测、可发现的直接操作流程。

本设计以 Origin 的画布优先范式为参照，但不复制其全部工作区或引入无关的科研绘图功能。

## 目标

- 让用户在画布上直接创建和调整标注，而不是依赖右侧表单按钮。
- 用紧凑图标工具箱、明确光标状态和短提示取代裸文字工具栏。
- 支持拖拽文本框，以及统一的“按下—拖拽创建”线、箭头、矩形与曲线操作。
- 保留现有图文档、命令栈、保存、恢复、撤销重做和导出契约。
- 让 Inspector 只承担精确数值、对象层级和高级样式的辅助职责。

## 非目标

- 不修改科学分析、数据源、样品数据库或 Origin 数据导出语义。
- 不加入自由手绘、任意脚本执行、通用 CAD 或多点样条曲线编辑器。
- 不改变已有图形对象的持久化标识、命令历史语义或数据绘图语义。
- 不将整个编辑器重做成完整的 Origin 多窗口工作台。

## 已确认的交互

### 总体布局：Origin Lite

编辑器使用轻量的 Origin 式布局：顶层菜单/现有编辑器主工具区保持；画布左侧提供
约 40px 的图标工具箱；画布继续占据大部分可用区域；右侧属性作为默认收起的抽屉。

工具箱按固定顺序提供：选择、文本、直线、箭头、曲线、矩形。每个入口都有图标、
中文工具提示、选中状态和相应光标。选择工具是默认状态；`Esc` 返回选择状态并取消未完成创建。

画布底部在创建状态时显示一行短提示，例如“文本：拖拽创建文本框”。它只解释当前
动作，不替代主界面或占用 Inspector。

### 创建与直接编辑

| 对象 | 创建 | 画布编辑 |
| --- | --- | --- |
| 文本 | 拖拽创建指定宽高的文本框；单击创建自动尺寸的短标签 | 创建后直接输入；选中后拖动对象和文本框边界 |
| 直线 | 按下—拖拽两个端点 | 拖动端点或整个线段 |
| 箭头 | 按下—拖拽两个端点 | 拖动端点或整个箭头；箭头端保留在样式中 |
| 矩形 | 按下—拖拽对角线 | 拖动边/角调整尺寸，或整体移动 |
| 曲线 | 按下—拖拽创建两个端点 | 选中后显示一个中间控制手柄；拖动它改变弧度 |

曲线采用用户确认的“两点拖拽 + 一个弯曲手柄”模型，而非逐点点击的多节点样条。
它与直线、箭头和矩形共享一个直观的创建手势，适合科学图中的引线、弧形指示与连接线。

创建成功后对象保持选中；拖动时只显示预览，鼠标松开时写入一次编辑命令。取消、无效
几何或离开可绘制区域不能留下空对象或半成品历史记录。

### 样式与 Inspector

选中对象后在靠近画布的紧凑上下文样式条中显示最常用且适用的选项：

- 文本：字体、字号、文字颜色、对齐。
- 线、箭头、曲线：颜色、线宽、线型、箭头端。
- 矩形：边框颜色、线宽、填充/透明度。

属性抽屉不再承载“添加文本、添加线、复制、粘贴、裁剪”等主要绘图入口。它保留对象树、
精确坐标/尺寸、层级、完整样式和文档级属性；只显示当前对象支持的字段。用户手动收起后，
选择对象不能再次自动弹开抽屉。

## 架构与数据流

图文档和编辑会话仍是唯一持久化与撤销来源。工具栏只持有临时工具状态及正在绘制的预览；
静态图片画布和生成图画布各自将鼠标事件转换为同一类对象添加/更新命令。

需要形成一个共享的工具状态与手势协议，覆盖工具选择、起点、预览、提交、取消、光标和
状态文字。它不能绕过图文档或各自渲染适配器直接保存 GUI 状态。

文本对象扩展为可选边界：拖拽文本框保存 `x`、`y`、`width` 和 `height`；短标签只保存
位置并由渲染器自动确定尺寸。曲线以两个端点和一个控制点表达，确保静态画布、Matplotlib
生成图、保存/恢复与导出都使用相同含义。旧对象缺失这些可选字段时必须保持可读可编辑。

上下文样式条通过既有样式/文本/几何更新命令更新选择对象；属性抽屉与工具状态都从当前
对象能力读取字段，而非维护第二份样式事实来源。

## 错误处理与可访问性

- 指针不在图形区域、拖拽长度为零或工具不适用于当前模式时，恢复选择工具并在状态区给出简短原因。
- `Esc`、`Delete`、`Ctrl+Z`、`Ctrl+Y` 保持现有快捷键含义；工具提示和状态提示提供鼠标路径的同等说明。
- 对无法以目标渲染器表达的对象，保存和导出应给出清晰警告，不得静默丢弃标注。
- 未选中对象时不显示失效控件墙；上下文样式条隐藏或显示最短的选择提示。

## 测试与验收

自动化覆盖必须包含静态图片和生成图两条路径：

1. 图标工具箱的顺序、选中状态、工具提示、光标与 `Esc` 行为。
2. 拖拽文本框、短标签、直线、箭头、矩形、曲线及曲线控制手柄。
3. 选择、移动、几何调整、取消、撤销/重做、保存/重新打开和渲染一致性。
4. 上下文样式条只显示适用字段；属性抽屉收起后不自动重新打开；画布尺寸不随属性切换缩小。
5. 旧图文档中没有文本边界或曲线字段的对象仍能加载。

手动验收应在真实 GUI 中使用鼠标完成一段“文本框 + 直线 + 箭头 + 曲线 + 矩形”的图注，
保存、重新打开并导出。验收时确认常规绘图不需要进入右侧 Inspector。

## 分阶段实现

1. 先收敛布局、图标工具箱、工具状态和上下文样式条，删除右侧面板的重复创建入口。
2. 为两类画布实现一致的文本框与拖拽对象创建协议，并补齐预览/取消行为。
3. 接入曲线控制手柄、精确属性、保存/恢复与导出回归。
4. 完成自动化与真实 GUI 验收，再提交审查。
