# Restarted GUI All-Mode Evidence Refresh Design

## Goal

Refresh the Windows-native route evidence for the current checkout across the
real technique modes plus synthetic Joint and IR mapping routes.

## Evidence boundary

The route harness starts fresh Qt/MainWindow instances in a native Windows
pytest process, restores each run through the persisted history contract,
captures Results, Gallery, History, and Editor, and exercises the existing
PackageExporter fallback. This proves route construction, populated state,
and export artifact creation. It does not prove scientific correctness,
vendor calibration, or owner publication approval.

## Review policy

Keep review-required IR mapping, assignment-limited NMR solid-C, and blocked
Joint conflict results visible in the captures. Font warnings, long evidence
rows, and inactive-surface readability remain recorded as review signals; no
visual claim is upgraded solely because the test assertions pass.

## Out of scope

No production code, real input, scientific threshold, publication role,
reviewer record, or cleanup policy changes.
